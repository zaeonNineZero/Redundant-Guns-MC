# Redundant Guns
Redundant Guns is a companion addon for NineZero's Gun Expansion and MrCrayfish's Gun Mod, adding even more weapons and attachments in the NZGE/CGM artstyle. This addon is for the enthusiast who enjoys having a large selection of guns to choose from -- many guns are variations on existing weapons in NZGE and CGM, or share the same role/niche as an existing gun, hence the 'Redundant' name.

**This is the source code for the 1.19.2 Development Branch, which will not reflect the state of the latest stable build for 1.19.2.** Source code for stable branches of the mod -- including for other versions of Minecraft Java Edition -- can be found in the branch dropdown menu once they are added.

All mod releases posted here are development or pre-release builds that are posted to solict feedback regarding upcoming changes or to hunt for bugs/issues before a major update. There is currently no CurseForge mod page at this time.

### Addon Features:
* Over 10 additional weapons to play with, all balanced around the default NZGE and CGM guns.
* One barrel attachment and one stock attachment, both being modified variations of existing NZGE attachments.
* Crafting recipes for all items, allowing them to be used in survival mode.
